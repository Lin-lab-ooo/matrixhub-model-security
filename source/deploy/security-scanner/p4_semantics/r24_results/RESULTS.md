# R24 本地结果摘要

作者：林天意、邹佳颖。当前源码6062、GEN199；本地交付，未线上发布。各组分开统计，不合并成总体准确率。

| 观察组 | 已观测结果与边界 |
|---|---|
| 公开原样正常3例 | CUNI、SASRec、YOLO均拒绝或不完整；复杂公开P4兼容缺口仍在，不能称误拒率下降。 |
| 公开受控风险原样4例 | 2例完整识别危险引用，2例未知/不支持拒绝；不能把4次拒绝算4个完整检出。 |
| 惰性机制派生2例 | 分列于原样本：有效例完整危险引用拒绝；截断例保留引用并不完整拒绝。 |
| P4结构控制6例 | 6/6符合具体预期：1完整放行、2长度矛盾拒绝、3缺记录拒绝；两遮蔽缺失由旧放行变为拒绝。非恶意TP。 |
| 原200与静态测试 | 原200技术通过，原oracle192/200；旧8项不改，双基线0新增回归。静态165+独立12项通过，非177个公开模型。 |
| MatrixHub/KIND APP5 | 3风险场景、每场景6正常文件、36次完整GET/SHA及4结构项通过；不是重新运行完整官方187项。 |
| 真实ResNet18 | 同一官方原件46,830,571B：当前源码完整放行35.733786秒。派生停在p2-storage-refs，4项未运行；整个6项实验FAIL。 |
| 真实DistilBERT | 同一267,954,768B Safetensors三次完整扫描及3次恢复通过：18.603061、18.766725、18.565508秒；仅1个模型。 |
| 合成SFT性能 | 18格、12份预封身份、ABBAAB、native上限4/批4；最大单文件256MiB、批1GiB，不是100GB实测。 |
| 作者ZIP资源样本 | 42,374B原样本约1.521241秒以archive_ratio_limit拒绝，恢复和身份检查通过；是资源防护观察，不是恶意TP。 |

合成1GiB批中位时延：7cd为22.013524秒，6062为21.848542秒，区间重叠；A源码来自G盘只读绑定、B来自镜像层，不能归因算法提速或P4增量成本。计时含产品完整AV、前后SHA及规则检查，剔除harness准备、验证hash、启动与恢复。真实模型结果与18格合成曲线分别呈现，不据小样本泛化安全性。GPU及训练投毒不纳入。

完整SHA、原始秒数、分组与收据索引见`final-observations.json`及`sample-observations.csv`；CSV明确区分单次观察、重复扫描、未运行项及组摘要。
